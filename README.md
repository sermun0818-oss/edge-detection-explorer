# Interactive Edge Detection Explorer

This project demonstrates classical edge detection methods used in image analysis.

## Features

- Upload your own images
- Compare Sobel, Laplacian, and Canny edge detection
- Explore parameter sensitivity
- View histograms and metrics

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
